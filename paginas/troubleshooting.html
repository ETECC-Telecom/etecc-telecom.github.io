O que é o Troubleshooting?

O Troubleshooting (Resolução de Problemas) é um processo lógico e sistemático de busca pela causa raiz de uma falha. Em vez de testar soluções aleatórias, o objetivo deste guia é orientar você através de uma estratégia de isolamento: eliminar variáveis até que reste apenas a origem real do problema.

Pilares do Nosso Padrão Técnico

Para garantir a eficiência de nossa operação e a satisfação do cliente, todo atendimento deve ser norteado por estes quatro pilares:

  1. Isolamento de Variáveis: Teste um componente por vez (Cabo, Conector, ONU, Roteador). Se você mudar duas coisas ao mesmo tempo, não saberá o que resolveu o problema.
  2. Abordagem Camada por Camada: Comece sempre pela Camada Física (cabos, energia, conectores) antes de avançar para configurações de software ou lógica de rede.
  3. Evidência Técnica: "O que não é registrado, não foi testado." Fotos de Power Meter, testes de velocidade e uso do laser são essenciais para o histórico do cliente e para o suporte de Nível 2.
  4. Foco na Experiência do Cliente: Resolver o problema técnico é apenas metade do trabalho. A outra metade é garantir que o cliente entendeu a solução e se sente confiante no serviço entregue.

Como utilizar estes guias

Abaixo, você encontrará os protocolos específicos para cada tipo de chamado. Cada guia foi desenhado para ser um fluxo de decisão:

  • Siga a ordem numérica: Os passos estão organizados do mais comum/simples para o mais complexo.
  • :Atenção aos alertas (⚠️) Pontos críticos que podem causar retrabalho ou danos ao equipamento.
  • Checklist de Encerramento: Antes de sair do cliente, valide se todos os pontos de teste do guia foram cumpridos.
